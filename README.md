# 钻石拼贴 · 玩法原型

验证"图样脉络 + 自由选色贴钻"核心手感的第一版原型(纯 Web,无依赖)。

## 运行

```bash
cd 钻石拼贴
python3 -m http.server 8765
# 打开 http://localhost:8765
```

手机体验:同一 Wi-Fi 下访问 `http://<电脑IP>:8765`(安卓 Chrome 有震动反馈,iOS Safari 无震动但音效正常)。

## 已实现

- 5 个数学生成的对称脉络模板:爱心 / 星星 / 曼陀罗 / 星月 / 玫瑰(28×28 网格)
- 16 色水钻色板(含幻彩 AB 钻),径向渐变 + 高光 + 随机相位闪光
- 贴钻交互:点按放置、滑动连贴、擦除模式、撤销(按笔画整段撤销)
- 音效:WebAudio 合成贴钻"嗒"声(随机音高)、擦除、完成琶音,无外部素材
- 震动:`navigator.vibrate`(安卓 Chrome)
- 进度条 + 贴满 100% 触发:闪白 + 扫光 + 完成卡片
- 导出:896px 高清 PNG(壁纸可用)
